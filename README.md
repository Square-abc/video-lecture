# 视频讲台 · Video Lecture Stand

一个纯网页版的实物展示工具，类似希沃视频展台，支持摄像头实时展示、批注、拍照对比、虚拟黑板等功能。

> 🎯 无需安装，打开浏览器即可使用。适配手机、平板、电脑。

![主界面](screenshots/main.png)

## ✨ 功能特性

### 核心展示
- 📷 **多摄像头支持** — 自动识别后置/前置，可手动切换
- 🔄 **画面旋转** — 支持 90°/180°/270° 旋转
- 🔍 **画面缩放** — 双指捏合、滚轮、按钮三种方式
- ❄️ **画面冻结** — 一键锁定当前画面，方便讲解

### 实时批注
- ✏️ **画笔批注** — 支持多色、多粗细、笔迹柔化
- 🧹 **两种擦除模式**
  - 滑动擦除：手指滑过哪里就擦哪里
  - 框选擦除：拖出方框批量擦除
- ↩️ **撤销** — 一键撤销上一笔
- 🎨 **虚拟黑板** — 画面变黑，可当黑板使用

### 拍照管理
- 📸 **拍照** — 保存当前画面到临时相册
- 🖼️ **照片标注** — 在照片上继续批注
- ⚖️ **并排对比** — 选两张照片对比展示
- 💾 **下载/删除** — 管理相册中的照片

### 交互优化
- 👆 **双指拖动/缩放** — 像看照片一样操作
- 🖱️ **滚轮切换工具** — 拖动/批注快速切换
- 📱 **移动端优先** — 小屏自动精简界面
- 🌐 **悬浮工具栏** — 三段分离，不遮挡画面

## 🚀 快速开始

### 方法一：在线使用（推荐）

访问 GitHub Pages 版本：
👉 **https://你的用户名.github.io/video-lecture/**

### 方法二：本地运行

⚠️ **注意**：由于浏览器安全策略，**直接双击打开 HTML 文件无法访问摄像头**，必须通过 HTTP/HTTPS 访问。

**推荐方式（Python 内置服务器）**：

```bash
# 进入项目目录
cd video-lecture

# 启动服务器（Python 3）
python -m http.server 8000

# 浏览器访问 http://localhost:8000
