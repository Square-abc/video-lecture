## 简介

**视频讲台** 是一款纯前端、零依赖（仅使用 Font Awesome 图标库）的网页应用。打开浏览器即可调用摄像头，在画面上实时批注、冻结、聚光灯讲解、拍照存档、录制视频。还内置了独立的黑板与白板容器，切换时互不干扰。

不需要安装 App，不需要上传服务器，所有数据保留在本地，随手打开就能用。

## 功能一览

### 摄像头展示
- 多摄像头枚举与切换（自动优先选择后置摄像头）
- 旋转 90° / 180° / 270°、水平镜像、垂直翻转
- 缩放 50% ~ 500%、拖拽平移
- 画面模糊（0 ~ 16 级）
- 冻结当前画面
- 帧率可调（10 ~ 120 fps，推荐 30 fps 省电）

### 批注系统
- 画笔：6 种预设颜色、粗细 1 ~ 24、柔化 0 ~ 20
- 橡皮：**滑动擦除**（默认）、**框选擦除**、**全部清空**
- 撤销 / 重做，最多保留 60 步历史
- 手掌擦除：三指同时触摸屏幕即可快速擦除
- 笔迹与摄像头画面分离，摄像头切换或旋转时自动重映射坐标

### 黑板 / 白板（独立容器）
- **黑板**：纯黑底 + 白色画笔
- **白板**：纯白底 + 黑色画笔
- 板模式使用独立坐标系，支持无限拖动、双指缩放
- **与展示批注互不干扰**：打开板时展示批注自动隐藏，退出板时原样恢复
- 每种模式的内容独立保存，再次进入自动恢复

### 拍照与相册
- 一键拍照（含批注合成）
- 相册管理：导入、下载、删除、清空
- 双图对比模式（A / B 分屏）
- 照片上可直接批注并另存为新照片

### 录制
- 基于 `MediaRecorder`，输出 WebM（部分浏览器支持 MP4）
- 可选采集麦克风声音
- 录制过程中可继续批注、冻结、切换工具

### 辅助工具
- 网格线（8.33% / 33.33% 双层）
- 聚光灯（跟随手指或鼠标）
- 秒表计时器（点击暂停 / 继续，长按归零）
- 全屏模式
- 数据导出 / 导入（`.sc` 二进制格式，包含照片、笔迹、设置）
- 一键重启应用（带二次确认）

### 国庆彩蛋（仅 10.1 ~ 10.7）
- 打开「画面调节」面板时，底部随机显示一条国庆祝福文字
- **纯文字**，无任何图形或图片
- 14 条文案随机切换，每次打开都不同
- 非国庆日期自动隐藏
- 预览方式：在 URL 后添加 `?national=1`

## 快速开始

### 环境要求
- 现代浏览器：Chrome / Edge / Safari（建议最新版）
- 必须通过 **HTTPS** 或 **localhost** 访问，否则浏览器会拒绝摄像头权限
- 需要摄像头设备

### 本地运行

```bash
# 方式一：Python 内置服务器
python -m http.server 8000

# 方式二：Node.js
npx serve .

# 方式三：直接部署到任意静态托管
# 如 GitHub Pages、Netlify、Vercel 等
```

然后访问 `http://localhost:8000` 即可。

> ⚠️ 直接用 `file://` 打开 HTML 文件无法访问摄像头，请务必使用本地服务器。

## 数据格式 `.sc`

导出文件为自定义二进制格式，包含：

- **头部**：JSON 元数据（版本号、导出时间、设置、照片索引、笔迹坐标）
- **照片区**：每张照片的原始字节（JPEG / PNG）
- **笔迹区**：展示批注、黑板笔迹、白板笔迹三组数据

笔迹坐标使用归一化存储（0 ~ 1），导入时按当前画布尺寸还原，因此换设备也能保持相对位置。

## 技术说明

- **纯前端**：无需后端，不上传任何数据
- **Canvas 分层**：`frame` 层绘制摄像头画面，`ink` 层绘制笔迹，互不干扰
- **PointerEvent 优先**：统一处理鼠标、触摸、手写笔，避免重复触发
- **请求动画帧节流**：按目标帧率绘制，降低 CPU 占用
- **localStorage**：保存画笔颜色、粗细、柔化、模糊、帧率、网格、镜像、录制音频等偏好
